# MIDI Dataset 🎵

This folder is used to store the MIDI files used for training the AI music generation model.

Add your `.mid` files here before running:

```bash
py preprocess.py
```

Example:

```text
dataset/
├── song1.mid
├── song2.mid
├── song3.mid
├── song4.mid
└── song5.mid
```

The MIDI files are not included in this GitHub repository due to file size and dataset considerations.

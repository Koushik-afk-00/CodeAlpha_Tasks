# FAQ Chatbot

A simple Python chatbot that answers questions about AI, Data Science, Python, and Machine Learning.

## Features

- Tkinter graphical interface
- FAQs stored in `faqs.json`
- TF-IDF text processing
- Cosine similarity for question matching
- Displays the best matching answer

## Technologies

- Python
- Tkinter
- Scikit-learn
- TF-IDF
- Cosine Similarity

## How to Run

Install the required library:

```bash
pip install -r requirements.txt
````

Run the chatbot:

```bash
py chatbot.py
```

## Example Questions

* What is AI?
* What is Python?
* What is Data Science?
* What is Machine Learning?
* What is NLP?

## Files

* `chatbot.py` - Main chatbot program
* `faqs.json` - Questions and answers
* `requirements.txt` - Required library
